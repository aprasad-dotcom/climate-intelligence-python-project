# Experiment to Feature Mapping

The supplied PAL write-ups establish six experiments (01–06). The PDFs contain readable aims, requirements and conclusion text, but portions of the original program/output pages are embedded as page images, so those code samples were not text-extractable. This map uses the readable teacher requirements and implements them in this project; it does not claim a verbatim copy of code hidden in those images.

| Experiment | Core topic | Required concepts | Climate application | Implementation | Demonstration | Verification |
|---|---|---|---|---|---|---|
| 01 — “Write a program to create a class with respect to the case studies given” (Experiment 01 source brief) | Classes and objects; encapsulation and methods. The write-up also includes a separate four-subject marks program requiring getter/setter methods. | Class/object, attributes, instance/static/class methods, a private member, getters/setters, simple calculation. | A climate reading is represented as a `ClimateObservation`; its temperature is encapsulated behind a validating property and it exposes an instance summary, class constructor and static unit-conversion helper. The separate marks exercise is retained as a support module. | `climate_engine.py`: `ClimateObservation`, `_temperature`, `temperature`, `summary()`, `from_mapping()`, `celsius_to_fahrenheit()`. `experiment_support.py`: `StudentMarks.get_marks()` / `set_marks()`. | In Project details explain the climate object; in the test suite show a student mark percentage and getter/setter update. | `test_experiment_01_getter_setter_and_static_class_methods`; `test_observation_constructor_and_validation`. |
| 02 — “Implement Constructors, and Lists” (Experiment 02 source brief) | Constructors and list-based object data management. ## Numbering and source notes

- The Experiment 06 PDF cover/title says Experiment 06, while an inner page contains a stray “Experiment No.: 01” line. The mapping follows the cover title and the Collections and Functional Programming assignment body.
- Experiment 02's heading identifies the topic as Constructors and Lists. Its conclusion refers to IMD rainfall records; those requirements are represented through the provided IMD-labelled dataset and rainfall field.
- Several sample programs and outputs are embedded as images. Their aims, requirements and conclusions were readable, but code hidden in those images could not be fully audited or compared line by line.
- This project uses the requested Climate Intelligence heatwave use case throughout its primary interface. The standalone student-mark exercise remains a small support example only because it is explicitly a separate task in the supplied write-ups.
