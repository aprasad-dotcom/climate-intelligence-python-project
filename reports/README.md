# Climate Intelligence — Three Project Reports

This folder contains three editable, five-page report perspectives for the Climate Intelligence Tkinter and SQLite mini project.

- **A — System Architecture:** components, data contracts, persistence, and experiment integration.
- **B — Data Analysis:** dataset handling, transformations, alert rules, and prediction limits.
- **C — UI and Validation:** application workflow, simulation, testing evidence, and limitations.

Each report is provided as an editable Word document and a matching five-page PDF review copy. The PDFs were rendered from the DOCX content for pagination and visual review; Word may paginate slightly differently on another machine or with different fonts.

The report identity fields are intentionally left as fill-in blanks. All six experiments are mapped in each report. Only the supplied authentic Overview screenshot is shown as an application capture; other UI paths are supported by source review and recorded smoke-test evidence, not presented as screenshots.

The reports preserve the distinction between imported observations, synthetic demo readings, and simple estimates. Their stated alert thresholds are educational project rules, not official IMD criteria, and the prediction is not a trained or accuracy-validated model.
