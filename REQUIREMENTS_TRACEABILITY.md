## Resolved conflicts and limits

- The separate screenshot reference describes a Flask/PostgreSQL browser site and uses a 35°C threshold. The user's explicit technology requirement and experiment 06's ≥40°C monitoring rule govern this project. The screenshots are used only as a visual reference for a dark analytics layout.
- Alert categories use the educational bands `NORMAL <37°C`, `WARNING 37°C–<40°C`, and `CRITICAL ≥40°C`. These are not official IMD heatwave criteria.
- The system estimates the next reading from the latest values; it does not contain a trained machine-learning model, external weather feed, or calibrated prediction interval.
- GUI operation code is present and app startup created the SQLite file, but the window itself could not be captured or driven via the enabled desktop-control surface. The professor should run `py app.py` on Windows for final visual validation.
